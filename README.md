# CoworkSpace

Платформа для бронювання переговорних кімнат у коворкінг-просторі. Зроблена для організаторів зустрічей які хочуть швидко знайти вільну кімнату і забронювати її, і для менеджерів коворкінгу які керують розкладом.

---

## Проблема і цінність

Без системи організатор шукає вільну кімнату вручну через менеджера, не отримує підтвердження і забуває про зустріч. CoworkSpace вирішує це: клієнт бронює онлайн, отримує confirmation_code і email-нагадування за 60 хвилин до початку.

---

## Що зроблено у семестрі 2

- Спроєктовано Feature #1 — автоматичне email-нагадування за 60 хв до бронювання
- Побудовано API-контракт: POST / GET / PATCH /reminder з повним каталогом помилок
- Спроєктовано UX-потік бронювання: 3 кроки з валідацією, Error Summary і a11y
- Пропрацьовано безпеку: матриця доступів, IDOR-захист, PII-правила
- Написано тест-дизайн: 15 тест-кейсів з трасуванням до AC

---

## Ключова Feature #1

Система автоматично надсилає email клієнту за 60 хвилин до початку бронювання. Якщо бронювання скасовано — нагадування скасовується автоматично. Якщо до початку менше 60 хвилин — надсилається одразу.

Три статуси: `scheduled` → `sent` або `cancelled`. Через API тільки scheduled → cancelled. Перехід → sent виконує тільки внутрішня система.

## Відомі обмеження

- Поштовий сервіс — мок. Реального email в демо немає.
- Race condition — захист є в коді, автотест відсутній.
- AC-7 (retry) — описано в специфікації, тест потребує мок поштового сервісу.
- UX-демо — статичний прототип, не підключений до реального API.
